# Viera Amber Hub

A creative & impact-driven ecosystem for feminine empowerment.

## About

Viera Amber Hub is an elegant, modern website showcasing:
- **Illustrations & Designs** — Narrative-driven fashion illustrations
- **VAGIN** — Girls' Initiative for SRHR awareness
- **VIVA** — High-end wearable art collection
- **VAM** — Digital design masterclass program
- **VASH** — Commerce hub for products and resources

## Tech Stack

- **React 19** with Vite
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **shadcn/ui** components
- **Framer Motion** for animations
- **React Router** for navigation

## Getting Started

```bash
# Install dependencies
npm install
# or
bun install

# Start development server
npm run dev
# or
bun run dev
```

The site will be available at `http://localhost:8080`

## Building

```bash
npm run build
# or
bun run build
```
